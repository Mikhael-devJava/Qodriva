# Qodriva

A local, open source static analysis tool for programming projects. It reviews
project structure, possible exposed secrets, Git hygiene and declared
dependencies, entirely on your machine.

> **Status:** under development (stage 1: project skeleton). The full README
> is written in stage 8.

Qodriva is a preventive and educational tool. It is not a complete security
solution and cannot guarantee the absence of vulnerabilities.
